# FitZone — Assignment 1 (starter)

**Course:** Web Application Development (CSSE3143)  
**Theme:** Gym & Fitness  
**Status:** Proposed design — obtain instructor approval before starting your own final implementation and Git history.

## Pages
- `index.html` + `home.css`: headings, text, image, links, selectors, typography, border and background.
- `media.html` + `media.css`: image, video, audio, ordered/unordered lists, table, box model, display, position, float and overflow.
- `register.html` + `register.css`: required input types, attributes, validation, selectors, combinators, pseudo-classes and pseudo-elements.

## Run
Open `index.html` in a browser or use VS Code Live Server. Navigation to Services, Portfolio and Contact is included as required for the eventual six-page site; these links will work once Assignment 2 pages are created.
